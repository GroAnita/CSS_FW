# Pink Club-Social Media Website

The Pink Club is a responsive social media style web application where users can explore posts, interact with content, and enjoy a playful, pink-themed user experience.
The project focuses on clean UI, accessibility and a modern front-end development practices.

## Features

- **Feed of posts** with images, likes and comments.
- **User profile** with images, bio and user posts.
- **Responsive navigation** with mobile menu.
- **Horizontal slider** (stories/reels moch up).
- **search and sort posts** (only UI for now).
- **Create new posts** (Only UI for now).
- **Custom Pink themed design system**

## Accessibility

- Semantic HTML
- ARIA labels for interactive elements
- Screen reader support for buttons and menus

## Performance Optimizations

- Lacy loading images
- Optimized Unsplash images using query parameters (w=400&h=200)
- Defined image dimensions to prevent layout shift

## Tech Stack

- **HTML**
- **TailwindCSS**
- **Vanilla JS**
- **Font Awesome**
